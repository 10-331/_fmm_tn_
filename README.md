# ひかりの直後 ほか ― 笹井綾関連の小品・実験置き場

笹井綾関連の小品や実験ページをまとめたリポジトリ。入口は短編「ひかりの直後」。

- 公開URL: https://10-331.github.io/_fmm_tn_/

## 中身

- `index.html` ― 「ひかりの直後」（入口）
- `gallery-project/` ― ギャラリー表示の実験
- `conversation-game/` ― 会話ゲーム形式の実験
- `filler_game/`、`yam/`、`hikaku/` ― 小品・検証用
- `works/` ― 作品置き場（ルート側と素材が一部重複している）
- ルートの単体HTML（Character、Secret、gallery、home、inception、record_filler、ssi、where、worldbuilding など）― 設定ページや単体ページ
- `test.html` ― プロフィール画面の試作ページ

## 編集ルール

- コミットメッセージは変更内容が分かる書き方にする
- ルートと `works/` で同じ素材を二重管理している箇所があるので、どちらを正にするか決めてから直すこと
